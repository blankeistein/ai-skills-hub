# Checklist review video

## Kritis
- [ ] Hook 3 detik pertama jelas dan spesifik; ada gerakan/teks langsung di frame 1
- [ ] Pesan inti bisa disebut dalam satu kalimat setelah menonton
- [ ] Audio bersih: suara tidak tertimpa musik, tidak ada clipping
- [ ] Teks layar terbaca di layar HP (tinggi minimal ±5% tinggi frame, kontras tinggi)

## Penting
- [ ] Ada perubahan visual/informasi tiap 3-5 detik
- [ ] Teks per scene ≤ 7 kata dan tampil cukup lama untuk dibaca (±0,3 dtk per kata + 1 dtk)
- [ ] Teks tidak tertutup UI platform (sisakan margin atas-bawah ±8% untuk 9:16)
- [ ] Gaya konsisten: font, warna, tipe animasi seragam antar scene
- [ ] CTA ada di akhir dan jelas satu tindakan
- [ ] Volume musik latar sekitar 10-20% saat ada narasi

## Opsional
- [ ] SFX ringan di transisi atau kemunculan angka penting
- [ ] Caption/subtitle selaras dengan narasi
- [ ] Frame terakhir tidak terpotong mendadak (beri 0,5-1 dtk jeda)
